# 从底层能力到直播工具

LiveConnect 的目标是让开发者用更少的重复工作完成四平台接入。统一事件可用于自定义弹幕覆盖层、礼物反馈、桌宠动作或主播工具箱，具体界面与业务规则由你的应用实现。

## FurryUP 官方产品

| 产品 | 适合谁 | 查看 |
| --- | --- | --- |
| FurryUP Studio | 希望直接使用完整主播端工作台、OBS 互动和系列联动的主播 | [产品介绍与已公开界面](https://github.com/frostynight-furry/furryup-studio-releases) · [安装包](https://github.com/frostynight-furry/furryup-studio-releases/releases/latest) |
| FurryUP 桌宠 | 希望在桌面体验角色陪伴与系列联动的用户 | [介绍与下载](https://github.com/frostynight-furry/furryup-desktop-pet-releases) |

以上为官方产品入口，不表示整个产品或每个功能都在本仓库开源，也不表示某个已发行安装包已包含本仓库所有最新修复。产品版本以各自发布说明为准。

## 社区接入案例

目前尚未收录经过核实的独立社区案例。欢迎提交公开项目链接、接入了哪些平台和事件、使用的 LiveConnect 版本，以及允许展示的截图或演示。截图请使用示例数据，不包含登录信息或实际观众隐私。

可通过 [功能建议表单](https://github.com/frostynight-furry/furryup-live-connect/issues/new?template=feature_request.yml)提交，并在标题注明“社区案例”。收录时会保留作者和项目链接，明确它是独立项目；不会要求你的产品使用 FurryUP 账户或植入广告。

## 如何观察开源效果

维护者可从公开接入案例、有效贡献者、问题反馈、仓库访问与产品入口访问了解项目是否帮助到了开发者。官网访问和产品安装需要由各自渠道提供统计，不能从 GitHub Star 数推算；当前没有在 SDK 中增加埋点、联网上报或安装追踪。
